# UI UX Specification Final

Input form uses direct q and `Tổn thất nhiệt (kW)`, not a percentage. N label: `Số mâm lý thuyết trong thân tháp`. Condenser select has Total/Partial. Result includes `Mô hình VLE: Raoult + Antoine`, `Phiên bản dữ liệu`, warnings and all residuals.

If extrapolated, display a persistent yellow warning naming the component, temperature and source range. A success badge must never override a warning. QC/QR are displayed only from engine. Sensitivity preserves condenser/q/heatLoss and varies exactly R, N or NF.
