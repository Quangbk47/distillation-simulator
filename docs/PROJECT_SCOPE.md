# Project Scope

Mục tiêu: mô phỏng Ethanol–Water có cơ sở khoa học để khảo sát vận hành và validation thực nghiệm.

Mốc 1: binary, steady-state, McCabe–Thiele, output chính, sensitivity R/N/NF, validation.
Mốc 2: hệ thứ hai + validation + đề xuất vùng vận hành; không tự chọn hệ thứ hai.
Ngoài V1: optimization, AI/ML, dynamic simulation, tray hydraulics chi tiết, dashboard phức tạp, UI chọn nhiều thermo model.
