# Validation Plan Final

Primary source may be literature/dataset because experimental data is not currently required. Every case records full citation, table/figure/page, original units, mapped inputs, mapping assumptions and observed outputs.

Report absolute error, relative error and MAE for xD/xB and other available values. The accepted V1 primary metric is `MAE_xD_xB_percentage_points`; the acceptance threshold is `5` percentage points. A case may be evaluated only after citation, condition mapping and observed data have been reviewed. Do not label a dataset validated merely because the configured threshold exists.
