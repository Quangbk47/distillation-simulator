# Validation data

Validation cases phải lưu citation đầy đủ, loại nguồn, điều kiện gốc, mapping input/units, observed values và assumptions. Nguồn literature/dataset được phép ở giai đoạn hiện tại; không được gắn nhãn PASS trước khi chuyên gia điền metric và threshold câu 10A.

Schema nằm tại `schema.json`. Case mẫu pending nằm tại `cases/ethanol-water.pending.json`.
