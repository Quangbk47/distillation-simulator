# Validation data

Validation cases phải lưu citation đầy đủ, loại nguồn, điều kiện gốc, mapping input/units, observed values và assumptions. Nguồn literature/dataset được phép ở giai đoạn hiện tại. V1 dùng MAE của xD/xB theo điểm phần trăm với ngưỡng `5`; không được gắn nhãn PASS khi case chưa được review và đánh giá.

Schema nằm tại `schema.json`. Case mẫu pending nằm tại `cases/ethanol-water.pending.json`.
